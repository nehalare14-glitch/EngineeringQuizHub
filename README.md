# EngineeringQuizHub

EngineeringQuizHub is a responsive, web-based engineering quiz application.

## Technology Stack

Frontend:
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

Backend:
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA

Authentication:
- Firebase Authentication

Database:
- Supabase PostgreSQL

Hosting:
- Vercel (Frontend)
- Koyeb (Backend)

## Main Features

- Google and email/password login
- Email verification and password reset
- Dashboard
- Engineering branch selection
- Difficulty-based quizzes
- Quiz results and explanations
- Mistakes and saved questions
- User profile
- Responsive Windows and Android interface
